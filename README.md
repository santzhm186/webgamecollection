# 玩得到 · Web Game Collection

把广告里常见的小游戏做成真正可以玩的网页版。使用原创图形、页面和关卡，除 Three.js 外不再添加依赖。

## 运行

需要 Node.js 20 或以上。首次运行前需安装依赖并生成 3D 资源：

```sh
npm install
npm run dev
```

打开 http://127.0.0.1:5173 。请通过 HTTP 访问，不要直接双击 HTML。

界面右上角可切换 **简体中文 / English**，选择会保存在本机浏览器。
也可用 `?lang=en` 直接指定语言（不写入设置，便于分享链接）。

> 注意：开发服务器只服务白名单内的后缀，并为每种后缀返回正确的 MIME。
> 新增资源类型（图片 / 音频 / glTF 模型）时必须同时加进 `scripts/serve.mjs` 的 `types`，
> 否则浏览器会拒绝执行或渲染 —— ES 模块尤其严格。

## 玩法与 v0.3 更新

| 游戏 | 内容 | 操作与规则 |
| --- | --- | --- |
| 加减门冲关 | 5 关：海岸、峡谷、暮色、赤沙补给线、极光远征 | ← / →、A / D 或触控选门，空格暂停。增益门改变队伍规模，每波守卫消耗人数，最后自动进行要塞交战。 |
| 拉针救人 | 8 关，水、岩浆、蜘蛛、可燃气体与支撑石桥组合 | 点击金色拉环。观察分区通道，先排除危险，再放下宝藏。独立危险可按不同安全顺序处理。 |
| 拧螺丝 | 8 关，3–8 片金属，6–22 颗螺丝 | 点击未遮挡的螺丝；三孔金属片需要拆 3 颗。整片脱落后释放对应暂存槽。前 3 关 4 格，后 5 关 3 格。 |
| 彩液分装 | 6 关，2–5 色液体、1–2 支空管周转 | 先选源试管，再选空管或顶层同色管；同色液层一起转移。支持提示与多次撤销。 |
| 星港推箱 | 6 关，从单箱直推到三箱调度 | 方向键 / WASD 或触屏方向按钮；货箱只能推不能拉，全部送到发光站台。 |
| 火力防线 | 5 关，每关约 25–50 秒，逐关 Boss | 自动开火，← / →、A / D、点击或拖动切换三条路。中路敌人逼近，两侧强化箱打破后获得散射、连射或护盾。空格暂停。 |

- 新美术：奶油白与墨绿街机收藏馆、原创色彩实验台主视觉、新游标签与关卡进度条、移动端双列卡片。
- 3D 资产：24 个可复用低多边形 GLB（约 473 KiB），统一坐标/材质/比例，附可旋转缩放的模型预览与下载页。机器人、货箱、敌机与 Boss 已接入游戏；WebGL 不可用时保留矢量画面。详见 [资产说明](src/models/README.md)。
- 关卡设计：保留旧关卡顺序，新增红色减员门、先清蛛网再排气、先架支撑桥再排石，以及 7/8 片机械棋盘。
- 画面：共享 Canvas / SVG 渲染，透视赛道、渐变能量门、队伍移动与射击、要塞血条；神庙石材、水流与岩浆；木纹工作台、金属厚度、螺纹与真实图层遮挡。
- 反馈：增减人数浮字、金属片脱落、点击粒子、成功与失败表现。可选合成音效，默认关闭。尊重系统的减少动态效果偏好。
- 成长：逐关解锁、每关三星、最高分、6 款游戏、38 关、共 114 星；本机浏览器保存，旧版通关记录自动迁移。
- 辅助：拉针安全提示、螺丝解法搜索提示、每关一次撤销（允许从槽满失败中恢复）。辅助操作会影响星级，不影响解锁。
- 触屏与键盘均可操作，切后台自动暂停冲关；关闭弹窗后停止游戏循环。
- 语言：界面文案与游戏内提示均走文案字典，支持中英切换；新增语言只需加一个文案文件，不用改任何界面代码。

## 数值规则

冲关使用整数兵力：先应用门的加成，再扣除当波守卫。到达要塞后双方按一对一交换兵力进行自动交战；到达人数不低于守卫人数即获胜。二星与三星按抵达兵力判断，不按动画帧率或操作耗时判断。

| 关卡 | 初始人数 | 守卫人数 / 一星 | 二星 | 三星 | 可通关路线 / 全部路线 | 最优抵达兵力 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 海岸训练营 | 16 | 110 | 130 | 145 | 16 / 32 | 156 |
| 峡谷突围 | 14 | 110 | 135 | 165 | 21 / 64 | 178 |
| 暮色要塞 | 12 | 250 | 380 | 560 | 18 / 128 | 693 |
| 赤沙补给线 | 20 | 220 | 320 | 420 | 24 / 256 | 464 |
| 极光远征 | 18 | 400 | 750 | 1200 | 33 / 512 | 1480 |

每关都有 2 条三星路线。以上统计来自对全部 992 条二选一路线的穷举，**不是玩家实测通关率**。

拉针不使用提示为三星，提示 1–2 次为二星，更多提示为一星。螺丝按提示与撤销的合计次数使用相同标准。彩液分装与推箱按各关目标步数判星，提示影响星级，撤销不扣星；火力防线按剩余生命与强化数量判星。星级不会因重玩而降低。

分数：冲关为「抵达人数 × 10 + 星级 × 250」；拉针为「机关数 × 200 + 星级 × 300」；螺丝为「螺丝数 × 100 + 星级 × 300」。不奖励重复点击或反复撤销。

## 验证与构建

```sh
npm test
npm run balance
npm run models
npm run build
```

测试还覆盖首页懒加载、卡片翻译、主按钮、螺丝撤销后的存档、模板输入与监听清理，以及加载中关闭或切换游戏。玩法测试涵盖 992 条冲关路线与星级门槛、2358 种拉针顺序、8 个螺丝棋盘的可解性、三孔片满槽释放、失败后撤销、提示解法与无效操作。新增测试还验证两款益智游戏的最短解与三星目标、连续撤销、射击游戏五关三星策略及 10/30/60/120 FPS 结算一致性，以及 GLB 的结构/几何/材质/包围盒。`balance` 输出可审查的数值报告。

`dist/` 可部署到静态托管服务，资源使用相对路径，兼容 GitHub Pages 项目子路径。仓库尚未自动启用网站部署。

## 文件结构

- `index.html` / `styles.css`：响应式合集、关卡选择、计分与辅助操作界面。
- `app.mjs`：游戏循环、交互、合成音效与本机进度。
- `games/`：每个游戏一个目录（manifest / engine / render / levels / assets），只依赖契约。
  - `games/runner/` 已完成迁移；`games/pins/` 与 `games/screws/` 的 manifest 已就位，引擎待 P4 搬运。
- `engine.mjs`：**过渡文件**，目前只剩 pins 与 screws 的规则层（P4 会拆分并删除）。
- `boards.mjs`：神庙与工坊 SVG 渲染及交互命中区域（P4 会拆到各游戏目录）。
- `src/core/registry.js`：游戏注册表（manifest 校验、id 冲突检测、坏模块隔离）。
- `src/core/lifecycle.js`：游戏会话（开局/推进/暂停/结算），纯逻辑无 DOM。
- `src/ui/scene/primitives.js`：Canvas 与 SVG 共享的绘制原语。
- `tests/games.test.mjs`：规则与数值测试（992 条冲关路线、2358 种拉针顺序、8 个螺丝棋盘）。
- `tests/dictionary.test.mjs`：命名与字典约定的强制校验（键集一致、无硬编码文案、依赖边界、渲染层可加载）。
- `games/water-sort/` / `games/warehouse/` / `games/shooter/`：三款新游戏的完整独立模块。
- `src/models/arcade-kit.js`：可复用模型源数据；`public/assets/models/`：GLB、清单与预览页。
- `scripts/`：本地服务器、构建、模型导出与平衡报告。
- `src/core/`：契约、枚举字典、i18n、多人契约、共享入口 `host-surface.js`。
- `src/locales/`：各语言文案。新增语言只需加文件 + 在 `locales.js` / `locales/index.js` 各注册一行。
- `src/core/multiplayer.js`：多人（同局多人）**契约预留** —— 玩家位、动作补丁、传输端口与接入路线。当前未实现任何适配器。
- `games/`：每个游戏一个目录，只依赖契约；`_template/` 是可直接改名的脚手架。
- [CONVENTIONS.md](CONVENTIONS.md)：**项目约定总表**（铁律、命名、字典、数据不变量、检查清单）—— 贡献前先读这份。
- `docs/`：[决策记录](docs/DECISIONS.md) · [架构方案](docs/ARCHITECTURE.md) · [命名与字典约定](docs/NAMING-CONVENTIONS.md) · [规模化与协作](docs/SCALING-AND-CONTRIBUTING.md) · [迁移映射](docs/MIGRATION-MAP.md)

目前使用确定性的玩法模型：冲关按兵力结算、拉针按机关状态推进、螺丝按几何遮挡判断。没有引入刚体或流体物理引擎。
