# 玩得到 · Web Game Collection

把广告里常见的小游戏做成真正可以玩的网页版。初版包含三个独立玩法，使用原创页面、图形和关卡，不依赖其他游戏的素材。

## 运行

需要 Node.js 20 或以上，无需安装第三方依赖。

```sh
npm run dev
```

打开 http://127.0.0.1:5173 。通过 HTTP 访问，不要直接双击 HTML（浏览器会阻止本地 ES 模块加载）。

## 初版玩法

| 游戏 | 操作 | 规则 |
| --- | --- | --- |
| 加减门冲关 | ← / →、A / D、点击或拖动赛道；空格暂停 | 选择增益门，扣除每轮守卫消耗，最后需要至少 160 人。 |
| 拉针救人 | 点击金色拉环，也可 Tab + Enter | 3 个关卡。按安全顺序处理蜘蛛、气体、水和岩浆，最后放下宝藏。 |
| 拧螺丝 | 点击螺丝，也可 Tab + Enter | 3 个关卡。上层金属片会遮挡下层螺丝；暂存槽最多 3 格，整片脱落后释放对应槽位。 |

游戏有胜负提示、重新开始、关卡切换。手机可触控操作。切换到后台时冲关游戏自动暂停。通关记录只保存在当前浏览器，可离线托管，无账号、广告或后端。

## 验证与构建

```sh
npm test
npm run build
```

`dist/` 是可部署到任意静态网站托管服务的成品，使用相对路径，兼容 GitHub Pages 项目子路径。仓库尚未自动启用网站部署。

## 文件结构

- `index.html`：游戏合集首页与游戏弹窗。
- `styles.css`：响应式界面。
- `app.mjs`：绘制、交互、进度存储。
- `engine.mjs`：独立的游戏规则。
- `tests/games.test.mjs`：胜负路径、关卡解法、遮挡和槽位规则测试。
- `scripts/`：零依赖的本地服务器与静态构建。

目前是玩法原型：冲关使用简化兵力结算，拉针使用离散机关状态，螺丝使用几何遮挡。后续可以扩展真实物理、音效、更多关卡和更多广告玩法。
