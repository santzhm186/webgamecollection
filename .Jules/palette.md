## 2023-10-27 - Remove redundant tab stops from large artwork buttons
**Learning:** Found that `.hero-art` and `.card-art` buttons in `index.html` were functioning as massive click targets that duplicated the text buttons ("先来一局" and "开玩") right next to them. For keyboard and screen reader users, this creates a redundant, confusing tab stop.
**Action:** Used the reusable UX pattern `tabindex="-1"` and `aria-hidden="true"` on these large art buttons. This preserves their mouse-click functionality (which sighted users appreciate) while hiding them from keyboard navigation and screen readers, effectively halving the number of tab stops per game without breaking the interaction model.
## 2023-10-27 - Remove redundant tab stops from large artwork buttons (Revision)
**Learning:** Initially tried to use `aria-hidden="true"` alongside `tabindex="-1"` on `.hero-art` and `.card-art` buttons to hide redundant tab stops. However, this was a severe regression because these buttons contain unique text content (like "Today's pick" and aria-labels for the game title) that the adjacent text buttons ("Play a round") do not have. Over-applying `aria-hidden="true"` hid this crucial context from screen readers.
**Action:** Reverted the `aria-hidden="true"` on the main art buttons, keeping only `tabindex="-1"`. This successfully removes the redundant tab stop for keyboard users while preserving the rich, informative context for screen reader users via virtual cursor exploration. Also applied `aria-hidden="true"` specifically to purely decorative icon spans within those elements.
